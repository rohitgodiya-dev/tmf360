# SOP outlines (for the quality team to write and approve)

Each SOP names the TMF360 screen and the controls that support it. The procedures are the organisation's
to own; these outlines only map them to the system.

| SOP | Covers | TMF360 support |
|---|---|---|
| TMF management | TMF plan, expected documents, filing timelines, completeness targets | eTMF plan, Placeholders, Navigator, TMF Health thresholds |
| Document filing and indexing | Intake, indexing, duplicates, filing level | Document Intake (server re-hash, duplicate status, AI suggestions if on) |
| Quality control of TMF documents | Inbound and post-approval QC, coded reasons, rework | Study Tasks, QC settings, electronic signatures |
| Post-filing corrections | Delete, deletion approval, reclassify, revision | Document actions with reasons and signatures |
| Certified copies | When and how to certify; who may certify | Certified copy action (signature bound to the file hash) |
| TMF oversight and risk review | Health review frequency, risk weights, oversight activities | Risk & oversight, TMF Health, Reports |
| Inspection readiness and inspections | Session set-up, scope approval, request handling, log retention | Inspection Mode, inspection log export |
| Archiving, retention and legal hold | Close-out, archive package, retention periods, holds | Archive & retention |
| Migration of TMF records | Mapping approval, exception handling, reconciliation and acceptance | Migration & import, import audit report |
| Use of AI assistance | Which capabilities are on, evaluation before use, human review | AI assistance switches and recommendation log |
| User access management | Joiners, movers, leavers; periodic access review | User management; User Management Audit Trail report |
| Change control and validation | As in `change-control.md` | Feature Management report, OQ/IQ scripts |

Training: each role is trained on its SOPs before access is granted. Keep the training record outside TMF360
(or file it in the study TMF, artifact 01.01.xx as defined by the organisation).
